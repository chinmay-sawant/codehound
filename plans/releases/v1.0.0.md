# CodeHound v1.0.0 — Release Notes

## One-paragraph summary

**CodeHound 1.0.0** is the first major product release of a **Go-first static analyzer**: a single Rust binary that combines security (CWE + opt-in taint), performance (PERF), and bad-practice (BP) detection with production CLI UX (profiles, baseline, ignores, incremental cache, SARIF/JSON). Across plan eras v0.0.1–v0.0.8 the project moved from a large prototype catalog to a restructured engine, real data-flow on core injection CWEs, a doubled BP catalog kept out of default CI packs, ~20× cold-scan speedups on real corpora, evidence-backed CWE maturity/quarantine, optional typed Go facts, and hardened delivery (CI supply chain, comment-only ignores, cache identity). Packaging completes the bar: multi-arch GitHub Releases with checksums + CycloneDX SBOM, and crates.io install via `cargo install codehound --locked`.

## Highlights

| Area | What ships in 1.0.0 |
|------|---------------------|
| **Security** | Large Go CWE catalog; **taint-gated** core paths (CWE-22/78/79/89/90/91) with intra- and same-package inter-procedural flow; maturity labels (Structural / Heuristic / fixture-only) |
| **Performance rules** | Dedicated **PERF-*** family (hot-path, alloc, cache/pool, frameworks) with tiers and a high-signal **recommended** default pack |
| **Bad practices** | Curated **BP** catalog (~136 rules) for service-level Go footguns; **off** in `recommended` / `perf` / `security` so default CI stays honest |
| **Adoption UX** | Profiles, baseline (`list` / `prune` / `update` / `diff` / `save`), ignore directives, incremental disk cache, export opt-in |
| **Speed** | Cold full re-analysis of gopdfsuit-scale trees on the order of **~230 ms** (from multi-second); warm cache hits in tens of ms |
| **Trust** | Pinned canary corpora, noise-reduction, FO quarantine for unproven CWEs, recommended-pack pilot (~95% actionable) |
| **Packaging** | Multi-arch binaries + SHA-256 + SBOM; crates.io publish on `v*` tags |

## Journey by plan era

### v0.0.1 — Foundation: Go CWE / PERF product surface

- Built the **Go-first scanner** with fixture-backed CWE detection (facts once per file, many cheap rules).
- Split **security (`CWE-*`)** from **performance (`PERF-*`)**; domain modules, registry/codegen, parallel `read → parse → detect` pipeline.
- Product surface: CLI (`--list-rules`, `--explain`, config, severity policy), **SARIF 2.1.0** / JSON, fingerprints, partial-failure resilience.
- Architecture/perf push: `SourceIndex`, fused AST walks, ParsePool/rayon, module size discipline.

### v0.0.2 — Production gaps: restructure, cache, baseline, taint

- **Codebase restructure** (six phases, public API preserved) so catalogs and detectors stay maintainable.
- **P2 pillars:** baseline / ignore-once, **incremental analysis** (disk cache, content hash, dep invalidation; large warm-cache wins), and **taint tracking** (graph, summaries, cross-function BFS) for core CWEs.
- PERF expansion through **213–224+** and enhanced batches; **BP** introduced as a third rule family (MVP → BP-65).
- Supporting contracts: stable finding identity, structured detector evidence, diagnostics/timings.

### v0.0.3 — Catalog growth + engine quality

- **BP catalog 65 → 136** (+71 curated rules across language, concurrency, HTTP frameworks, data, observability, testing) with admission gates and ~368 fixtures.
- Profile honesty: BP remains **advisory** (`style` / `bp` / `all`), not in recommended/security defaults.
- Parallel **Rust engine remediation**: scan lifecycle, cache cold/warm parity, function-local taint, typed wire boundaries, docs/Clippy gates (review scores lifted to ~9.7–9.8 on closed ledgers).
- Deferred intentionally: fix engine, deep taint edge cases, many speculative BP candidates.

### v0.0.4 — Cold-scan performance & docs gate

- Made the larger catalog **CI-viable**: gopdfsuit cold scan **~5s → ~229 ms** with **unchanged** finding oracle (943).
- Per-rule timing, NEEDLES/short-circuits, `ProjectSnapshot` prewarm, parallel cache preflight, selective rule skips when unused.
- **`missing_docs` zero-warning** policy on the public API.

### v0.0.5 — Trust over rule count

- **CWE catalog trust program:** domain freezes, NEEDLES audits, call-facts rewrites when oracle-safe, maturity + canary gates; fixture-only rules quarantined rather than marketed as Structural.
- **noise-reduce-1** and pinned multi-repo canary corpus; recommended pack pilot on real repos (**~95% actionable**).
- Architecture: scan-scoped BP facts, taint symbol/package hygiene, plugin deps, fail-closed registry, detector lifecycle hooks.
- **Phase 5 gates (G1–G6)** evaluated and mostly deferred with reopen criteria (typed Go, advanced taint, Python, BP long-tail, etc.).
- Explainability: `codehound rules` surface (id, pack, maturity, quarantine).

### v0.0.6 — Residuals closed; gates proven with evidence

- **R1–R8** residual security families dispositioned (mostly fixture-only keep; sensitive-fields heuristic retained where sinks justify).
- **G4 Typed Go:** optional `--typed` / `go list` package facts on master (tree-sitter remains default).
- **G5** channel capability **contract locked** (no invented assignment edges); channel/select edges still deferred.
- **G1/G2/G6** remain deferred (reopen fail / Gate B fail / Go-first ADR 0005).
- Post-batch canary + recommended-pack pilot held stop-the-line budgets.

### v0.0.7 — Hardening (ponytail + delivery)

Epic-level remediation (taint correctness, CI, ignores, cache, export/CLI):

| Stream | Outcome |
|--------|---------|
| **Taint P1** | Sanitizer honesty (`html.UnescapeString` not a sanitizer), receiver-qualified symbols, drop unsound CWE-22 suppress, closure stack restore |
| **Ignores** | Directives only from real comments — not string/raw-string bodies |
| **Cache / facts** | Project-relative identity, durable flush, fact/needle gating from enabled rules |
| **Export / CLI** | Owned staging, format contracts, UTF-8-safe context, atomic diagnostics, SARIF evidence fallibility |
| **CI / supply chain** | Strict post-SARIF action gating, release validation job, pinned inputs, MSRV all-features, `SECURITY.md` |

### v0.0.8 — Go taint v1 productization (roadmap ledger)

- **Theme:** same-module **cross-package** taint (import-path identity → hops → one precision lift → honest security pack growth).
- **Status in plans:** canonical next Go-only slice; **not** a second language or BP/PERF long-tail expansion.
- Success bar: multi-package fixture fires under `--taint`; `--typed` affects identity when toolchain present; same-package suite stays green.

## Product surface at 1.0.0

### Profiles & packs

- **`recommended`** (default): high-signal PERF + taint-core allow-list; BP off; fail-high posture for CI.
- Also: `perf`, `security`, `style`, `all` — expand coverage deliberately rather than by default noise.

### Analysis features

- **CWE** detectors with explicit maturity; taint for core injection-style CWEs (`--taint`, `--taint-depth`).
- **PERF** tiers and hot-path-aware rules.
- **BP** full catalog available under style/bp/all profiles.
- Optional **`--typed`** Go package facts (`go list`) for identity/resolution paths when the Go toolchain is available.

### CLI / workflow

- Baseline lifecycle and suppressions for adoption on legacy trees.
- Incremental cache (`--no-cache`, cache dir / rebuild / prune).
- Reporting: text, JSON, SARIF; export context/chunks **opt-in**.
- Rule explain / list surfaces for operators and reviewers.

### Delivery

- Multi-arch release binaries (Linux, macOS, Windows) with checksums and CycloneDX SBOM.
- crates.io publish on version tags; maintainer guide in `documents/releasing.md`.
- Composite GitHub Action for SARIF-oriented CI; Dependabot on Cargo + Actions.

## Breaking changes & migration (0.x → 1.0)

Carry-forward from the 0.1 product bar (still relevant at 1.0):

| Change | Migration |
|--------|-----------|
| Default profile is **`recommended`** | Pin `--profile all` / packs if you previously expected full catalog noise |
| Fingerprint **v2** (message-stable) | **Regenerate baselines** after upgrade |
| Export **off by default** | Pass `--export-context` / `--export-chunks` when needed |
| Invalid `--format` + `--no-terminal` combos | Rejected — fix CI invocations (v0.0.7 contracts) |
| Go-first features | Python is opt-in (`--features python`); TypeScript stub removed |

## Explicit non-goals (still true at 1.0)

- Replacing **staticcheck**, **govulncheck**, or **CodeQL** whole-program analysis.
- Security-grade multi-module / whole-world taint without evidence.
- Broad **Python** multi-rule catalog (ADR 0005 demote; Gate B not passed).
- Autofix / fix engine, LSP, or long-running daemon.
- Shipping fixture-only CWEs as Structural maturity.
- Expanding BP long-tail (G1) without canary reopen evidence.
